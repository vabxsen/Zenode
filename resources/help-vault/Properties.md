# Properties

The table at the top of this note is its **properties**: structured fields stored as YAML front matter between `---` lines.

- Click a value to change it. Each property has a type: text, number, checkbox, date, date & time, list or tags.
- Click the small icon in front of a property to change its type (that type is then used for that property name in every note) or to remove it.
- **+ Add property** adds a new one.
- `tags` are searchable and listed in the Tags panel; `aliases` are other names the quick switcher and links will find.

Editing a property rewrites only that part of the YAML: comments and the order of other fields are kept. In Source mode (command "Toggle Source mode") you see and edit the raw YAML.

Templates can bring properties with them: see [[Daily notes and templates]].
