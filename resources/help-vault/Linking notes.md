# Linking notes

Type `[[` to link to another note: suggestions appear as you type. A link to a note that doesn't exist yet is shown dimmed; click it to create the note.

- `[[Getting started]]` links to a note.
- `[[Getting started#Tabs and panes]]` links to a heading, `[[Note#^block-id]]` to a block.
- `[[Getting started|the basics]]` shows different text: [[Getting started|the basics]].
- `![[Canvas]]` **embeds** a note, image, PDF, audio or video in place.
- Ordinary Markdown links work too: `[text](Other%20note.md)`.

## Backlinks and mentions

The **Backlinks** panel (right sidebar) lists every note that links to the open one, with the line around each link. Open **Unlinked mentions** below it to find notes that name this note without linking it, and turn them into links with one click.

## The graph

**Ctrl+G** opens the graph: every note as a dot, every link as a line. Hover to highlight a note's neighbours, click to open it, drag to rearrange. The settings button filters by search, shows tags and attachments, and adjusts the forces.

## Renaming

Rename or move a note and every link to it, in notes and canvases, is rewritten so nothing breaks.

See also [[Markdown syntax]] and [[Canvas]].
