# Canvas

A canvas is an endless board for cards: text, notes from your vault, images and web links, connected by arrows and grouped in labelled areas. Canvases are `.canvas` files in the open JSON Canvas format, so other apps can read them.

- Make one from the ribbon or the file tree menu ("New canvas").
- **Double-click** empty space to add a text card; double-click a card to edit it.
- Drag from a card's side handle to connect it to another card, or drop on empty space to create a connected card.
- Drag to move, use the corner to resize, and Shift-click or drag a box to select several.
- Pan with Space+drag, the middle mouse button or the scroll wheel; zoom with **Ctrl+scroll**.
- Ctrl+Z / Ctrl+Shift+Z undo and redo.
