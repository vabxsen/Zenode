# Keyboard shortcuts

Change any of these in **Settings → Hotkeys**: click **+** next to a command and press the keys.

| Shortcut | Action |
| --- | --- |
| Ctrl+P | Command palette |
| Ctrl+O | Quick switcher |
| Ctrl+N | New note |
| Ctrl+S | Save now (notes also save as you type) |
| Ctrl+W | Close tab |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |
| Alt+← / Alt+→ | Back / forward |
| Ctrl+Alt+arrows | Move to the pane left, right, above or below |
| Ctrl+E | Reading view on or off |
| Ctrl+F / Ctrl+H | Find / find and replace in the note |
| Ctrl+Shift+F | Search all notes |
| Ctrl+G | Graph view |
| Ctrl+Shift+D | Today's daily note |
| Ctrl+\\ | Show or hide the left sidebar |
| Ctrl+Shift+B | Show or hide the right sidebar |
| Ctrl+Shift+O | Open another vault |
| Ctrl+, | Settings |
| Ctrl+= / Ctrl+- / Ctrl+0 | Zoom in / out / reset |
